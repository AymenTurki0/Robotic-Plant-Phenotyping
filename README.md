# Robotic-Plant-Phenotyping
End-to-end robotic framework for 3D plant phenotyping via monocular RGB. Features JetCobot multi-view capture (ROS 2/MoveIt2), NeRF/3DGS reconstruction (COLMAP, MASt3R), Barlow Twins SSL adaptation for robust 3D segmentation (+1.72 pp mIoU), Laplacian skeletonization, and RGB plant health mapping.
