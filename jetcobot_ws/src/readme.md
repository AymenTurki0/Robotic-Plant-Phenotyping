# ROS 2 Workspace

ROS 2 packages for the JetCobot system, including simulation, motion planning, robot description, and automated scanning.

**ROS 2 Inspector** was used for static architecture analysis and visualization. The generated graph is available as `ros2inspector_graph.html`.

[ROS 2 Inspector](https://github.com/aminebensaid66/ros2_inspector) · [Documentation](https://discourse.openrobotics.org/t/ros-2-inspector-static-architecture-analysis-and-visualization-for-ros-2-workspaces/57523)
