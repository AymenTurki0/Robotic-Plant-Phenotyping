# JetCobot Description

This package contains the JetCobot robot description, meshes, and URDF files.

The main robot model used in this project is **`jetcobot2.urdf`**, developed by modifying the original **`jetcobot.urdf`** provided with the JetCobot platform.

The original JetCobot resources are available in the [**JetCobot Google Drive**](https://drive.google.com/drive/folders/17ESHzZz1as8qinYm-W5RJok3hkD-Tmsp?usp=drive_link).
