
# Reconstruction Outputs

This folder contains the outputs generated by the different 3D reconstruction pipelines.

The reconstructed point clouds are stored as **PLY files**. Since these files can be large, the complete reconstruction outputs are **not included in this GitHub repository** to keep the repository lightweight and manageable.

The outputs can be generated by running the corresponding reconstruction pipelines using the dataset loaders and input images provided in this project.

Typical outputs include:

```text
output/
├── COLMAP/
│   └── *.ply
├── MASt3R/
│   └── *.ply
├── NeRF/
│   └── *.ply
└── Gaussian/
    └── *.ply
```

> **Note:** The large PLY reconstruction files are excluded from the repository due to their file size.
