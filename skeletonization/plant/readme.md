# 🌿 Plant Data

This folder contains the 3D point cloud model for **Ribes_04**, sourced from the **PLANesT-3D** dataset[cite: 1]. The dataset provides ground-truth annotations for semantic classes (leaves and stems) as well as organ-level instance segmentation[cite: 1].

---

## 📑 Reference

> **PLANesT-3D: A new annotated dataset for segmentation of 3d plant point clouds**[cite: 1]  
> K. Mertoglu, Y. Salk, S. K. Sarikaya et al. (2024)[cite: 1]
