# Skeletonization Outputs

This folder contains `.ply` files generated during the skeletonization pipeline:

* **Skeleton (`.ply`)**: Reconstructed plant backbone and central axes.
* **Topology (`.ply`)**: Structural graph nodes and connectivity network.

## Visualization

You can open and view these files using **[CloudCompare](https://cloudcompare.org/)**.

1. Download and install **[CloudCompare](https://cloudcompare.org/)**.
2. Drag and drop the `.ply` files into the CloudCompare workspace to inspect the 3D structures.
